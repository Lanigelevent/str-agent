# D3 · 决策（ADR 摘要）

> 内部决策台账的公开精编版。每条：决策 → 为什么 → 被有意接受的代价。
> 内部编号保留在括号里，便于设计讨论精确引用。

## 产品形态

| ADR | 决策 | 被接受的代价 |
|---|---|---|
| AD-004 | **core 零三方运行时依赖**（host 的 PDFBox 与 Batik 是两个经审计的例外，AD-042/043）。 | 从 JSON 解析到数字归一全部手写手测；工程成本巨大，换来供应链的绝对控制。 |
| AD-020 | 纯 agent 插件：无 APK、无桌面应用、无 UI。 | 放弃自有分发渠道；呈现层归宿主。 |
| AD-013/024 | 不做 NL 转 SQL。调用方给 SQL，工具执行并审计。 | 少一步「魔法」；执行侧安全（只读账号+看门狗）才是真正的边界。 |
| AD-022 | 预测 / what-if 是**确定性统计**，不是机器学习。 | 无学习模型；可预测性与可重放性保全。 |

## 信任与门禁

| ADR | 决策 | 被接受的代价 |
|---|---|---|
| AD-003 | 审计是**代码**（`verifyReport`），不是 LLM 自评。 | 会漏白名单之外的转写表达；但没有任何东西能「哄骗」正则加重放门禁。 |
| AD-028 | **所有报告出口**过同一确定性门禁（classic、agent、编辑部）。 | 门禁常开；`gateFailed` 是契约的一部分。 |
| AD-031 | 语义指标是可执行定义（表达式+维度+自检 DSL），编译到共享求值器。 | 无 dbt 式血缘与 UI；冲突挡在写入时而非查询时。 |
| AD-032 | 断点是增强不是依赖——断点目录不可写时退回纯内存执行。 | 同机多进程跑同一任务会互撞。 |
| (T-192) | 断言级溯源：定性断言必须锚定证据实体。 | 启发式召回有漏网；被标记的断言是软问题（质量注记），不是硬失败。 |

## 协议与运维

| ADR | 决策 | 被接受的代价 |
|---|---|---|
| AD-007 | MCP 桥默认绑回环 + Bearer。 | 要局域网访问必须显式配置。 |
| (T-146) | 远程绑定 **fail-closed**：未配 OAuth 2.1 issuer 拒绝启动。 | 静态 token 的远程部署被完全排除。 |
| AD-037 | 协议演进：声明 `2026-07-28` 无状态核心 + 12 个月旧 `initialize` 弃用窗口。 | 兼容期结束前要维护两条协议路径。 |
| AD-025 | 运行时注册表是工具面的唯一事实源；文档是带日期的快照。 | 快照文档按设计会漂，且自己声明这一点。 |
| AD-039 | 外部基准必须可离线复算；缺数据 = 显式 SKIP（SKIP 也算证据）。 | 外部分数只测协议层，不是报告质量结论。 |

## 性能与数据

| ADR | 决策 | 被接受的代价 |
|---|---|---|
| AD-019 | 双轨数据层：报告恒走 tier-1（内存 ≤1 万行）；DuckDB 服务探索。 | 两个引擎要保对拍——由逐样本交叉校验强制。 |
| AD-008 | classic 流水线是永久默认与回落。 | 两条生成路径都要维护；失败无感降级。 |
| AD-040/042/043 | 依赖钉定：kotlinx 家族对齐；PDFBox 管 PDF 文本、Batik 管 SVG 栅格化——都封在 `host`。 | AD-004 的两个重量级例外，各配专属 ADR。 |

## 评测哲学

Bench 是回归记分卡，**不是**模型质量背书。人类双盲标注才是真实质量结论的唯一来源；
在此之前，文档里所有质量声明都收敛到机器能证明的范围（接线、确定性、门禁覆盖）。
