# D1 · 项目概览

> 内部概览文档的公开精编版。定位、适用范围、角色、术语表与文档导航。

## STR AGENT 是什么

STR AGENT 把「导入数据 → 清洗 → 计算指标 → 编写报告」压缩成**一次工具调用**。
它是一个无头 MCP 服务器（stdio 与 Streamable HTTP 双传输），产出中文或英文分析报告，
并围绕一条不可妥协的性质构建：**报告里的每个数字都经机器校验、对照真实数据派生的
白名单逐个核实，每一次分析步骤都可按需重放。**

## 它不是什么

- **不做自然语言转 SQL**——调用方自己给出 SQL（仅 `SELECT`/`WITH`）；工具只执行并审计。
- **不做 UI、不发安装包**——它是纯 agent 插件，由宿主进程装配。
- **默认不执行任意 Python**——存在可选的沙箱计算档，默认关闭，开启等同授予代码执行权限。
- **单机定位**——不做多租户、不做水平扩展。

## 术语表

| 术语 | 含义 |
|---|---|
| `tier-1` | 内存分析引擎（≤ 10,000 行）。**报告路径恒走此档**——数字可逐行回溯。 |
| `tier-2` | DuckDB 列式引擎。服务探索与大聚合；从不产出最终报告。 |
| 数据契约 | 四条冻结的 `stragent_*` 工具（导入/画像/聚合/回看行），带跨语言金标夹具。 |
| `verifyReport` | 确定性数字溯源门禁。白名单外数字判「未溯源」；算式按数据重算。 |
| 溯源清单 | 每次工具调用留痕（参数哈希、结果哈希、数据集哈希），可**按需重放**。 |
| 编辑部 | 多角色报告管线（主笔 → 门禁 → 审校 → 修订环），带有界并行记者线。 |
