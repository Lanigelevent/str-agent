# D2 · 架构

> 内部架构文档的公开精编版。模块分层、数据流、执行保证、部署与诚实限制。

## 模块图

```
core/           分析、报告、校验逻辑——纯 Kotlin，零三方运行时依赖；语义唯一真值源
str-agent/      agent 引擎插件：编辑部编排、agent 循环、断点续跑、插件契约
data/           端口适配层：HTTP LLM 客户端、数据存储、MCP 桥、OAuth 资源服务器、PII 盾接线
engine-duckdb/  tier-2 列式引擎（DuckDB JDBC）
bench/          13 个评测套件、性能回归门、覆盖率基线
host/           参考宿主 + 无头 MCP 桥进程
```

依赖方向严格单向：`host → data → str-agent → core`；`bench` 与 `engine-duckdb` 旁路依赖 `core`。
`core`/`str-agent` 的公开 API 面由二进制兼容快照钉住（`apiCheck`）——公开面增长是有意识动作。

## 运行时调用链

```
MCP 客户端 → McpBridge.dispatch（一份 JSON-RPC 实现，stdio + HTTP 共用）
          → 工具层 → 业务层（core）→ LLM 端点 / DuckDB / kv 存储
```

工具面**按形态下发**：注册 53 条、默认形态 44 条。受控计算工具仅在沙箱获授权后下发；
`db_*` 工具仅在数据库面显式启用后下发；视觉工具仅在配置视觉端点后下发。
**目录裁剪隐藏工具但不删能力**——调度面全量保留，调用侧授权照常生效。

## 报告管线（六步）

1. **导入与画像**——数据经契约工具进入；列类型推断连同理由写进回执。
2. **简报装配**——数据统计、语义指标、注入净化汇成证据语料。**简报里的数字就是白名单。**
3. **生成**——编辑部主笔按章节产出（有界并行扇出），进度帧随产随流。
4. **报告门禁（与引擎无关、确定性）**：
   - `verifyReport`：白名单外数字标记；算式按数据重算
   - 断言级溯源：定性断言需要证据实体
   - 写作审计（套话/篇幅/结构块）
   - 硬问题触发 ≤ 2 轮修订；未清零则 `gateFailed` 如实标记
5. **语义审查（LLM）**——可以失败；失败**显式**写进 `qualityNotes`，绝不静默当「已审」。
6. **溯源落账**；结果 text 与 structuredContent 双发。

## 执行保证

- **断点续跑**：长任务持久化原子断点；崩溃后重跑不重复已完成轮次。孤儿断点启动时清扫（7 天窗口）。
- **取消**为协作式且跨传输传播。
- **预算**：逐步 token 上限 + 端点 400 回落；LLM 对冲调用带令牌桶成本上界；流式看门狗约束尾延迟。
- **PII 盾（可选）**：出站 LLM 流量按确定性单请求映射脱敏；入站按同一映射还原。

## 部署

- HTTP 传输默认绑 `127.0.0.1:7787` + Bearer（CSPRNG 128-bit、常量时间比较）。远程绑定
  **fail-closed**：未配 OAuth 2.1 issuer（RS256）拒绝启动，按主体分桶限流。
- stdio 传输以进程边界为信任边界。
- Docker 镜像按 manifest digest 钉定。

## 诚实限制（节选）

- 数字门禁是**语法级不是语义级**：证明数字有出处，不证明结论「好」。
- >1 万行文件的报告基于确定性系统抽样——抽样口径在每份回执中明示。
- 语义审查层是启发式，复杂行文可能漏过。
- macOS 未实测（Windows 与 Linux 在 CI 全量门禁）。
- Tasks 仅进程内（有界、重启即失）。
